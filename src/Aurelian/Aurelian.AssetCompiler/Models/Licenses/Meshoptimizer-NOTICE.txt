Offline LOD compiler dependency
Meshoptimizer.NET 1.0.7, package repository commit 8ae428f8ef490afed28bf516723859f24cbc6ea8
https://www.nuget.org/packages/Meshoptimizer.NET/1.0.7
https://github.com/BoyBaykiller/Meshoptimizer.NET
Native meshoptimizer: https://github.com/zeux/meshoptimizer
The pinned package supplies win-x64 and linux-x64 native binaries. Windows x64 is qualified here.
This adapter calls the native C API for simplification and vertex-cache optimization.
No Aetheris source is used.
