# @copeland/tscl

Project-local `tscl` launcher for Copeland TS `0.1.0-preview.1`.

```console
npm install --save-dev @copeland/tscl@0.1.0-preview.1
npx tscl --version
```

Preview 1 carries a framework-dependent Windows x64 tool payload and requires
the .NET 10 runtime or SDK. It does not install a global tool, clone a source
repository, or build Copeland on first use. Linux, macOS, and Windows Arm64 are
not package-tested for this preview.
