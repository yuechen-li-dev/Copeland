# Font Fixtures

`SpaceMono-Regular.ttf` is a checked-in deterministic test fixture for the M8g Typography/OpenFont outline extraction proof.

- Source: [googlefonts/spacemono](https://github.com/googlefonts/spacemono)
- License: SIL Open Font License 1.1
- Local license copy: `SpaceMono-Regular.LICENSE.txt`

`CrimsonText-Regular.ttf` is a checked-in deterministic proportional fixture for the M8n CPU MSDF spacing and kerning proof.

- Source: [google/fonts/ofl/crimsontext](https://github.com/google/fonts/tree/main/ofl/crimsontext)
- License: SIL Open Font License 1.1
- Local license copy: `CrimsonText-Regular.LICENSE.txt`

Tests in `Machina.Fonts.Tests` load this file directly from the repo or copied test output. They do not depend on OS-installed fonts.
