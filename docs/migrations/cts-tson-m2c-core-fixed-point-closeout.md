## JavaScript nominal-carrier repair

The defect was that symbols are discoverable and transferable: copying every Symbol property from a frozen null-prototype carrier created a structural counterfeit. `JavaScriptBackend` now creates a private `WeakSet` per generated record and enum family, registers each legitimate constructor result, and validates membership before any carrier slot access. There is no public token or registry, and record validation no longer enumerates symbols. The changed generated artifacts are the TSON record/asset corpus plus the JavaScript record/enum/Result/table corpus artifacts listed and hash-pinned in `JavaScriptCorpusTests`; their changes are the intentional shared carrier hardening only.

## Ratified boundary

M2c retains one shared parser, Object TypeScript and canonical TSON profiles, the six semantic variants, nominal runtime encoding, stable identity, compile-time assets, exact binary64/Unicode/limit laws, fixed-point evidence, and demand-only code generation. It adds no runtime decoder/parser/filesystem/compiler-host dependency, JSON, reflection, dynamic traversal, arrays, Results, tables, optionality, interfaces, aliases, or unsafe construction API. **TSON arrays** are the next separately approved expansion and are not started here.
