# MachinaCanvas, Aetheris, and Sprite Card lineage

The history was useful but not clean. MachinaCanvas accumulated separate TOML guide, blockout, sprite, and overlay systems because each solved immediate imported-image work. Those systems proved that named crops, datum alignment, coarse blockouts, selected-only focus, audit colors, and overlays are valuable. They also duplicated attachment and storage concerns and made sidecars look more authoritative than they should be.

Aetheris/Firmament independently established a stronger semantic law: named non-materialized structures and paths let authoring refer to meaning rather than kernel topology; selectors resolve against current semantic state; construction scaffolding may erase before product output. Its exact CAD APIs, units, planes, face selectors, and B-rep laws do not belong in sprite authoring.

Copeland M15 supplied the missing current owner chain. A columnar region catalog and ordered edge programs compile into immutable asset IR. The sprite-independent allocator produces concrete spans. SpriteForge validates runtime metadata, Machina lowers it, and Aurelian renders it. The M15 MachinaCanvas Sprite Cards correctly remained read-only, but that left visual programming incomplete.

M16 combines the useful laws:

- MachinaCanvas guides/datums/blockouts become kinds of compiler-retained authoring concept, not sidecars.
- Aetheris Concept Path becomes a bounded graphical path, not a copied language feature.
- Aetheris erasure becomes an explicit runtime-survival fact; scaffolding is omitted from runtime TOML.
- M15 edge programs and allocator remain authoritative and are projected, never simulated.
- Oblivion adds source-hash-guarded semantic edits and a deterministic card/overlay view.

The rejected return paths are equally important: no React port, TOML authority, arbitrary workflow API, global ontology, general selector/query language, B-rep-style topology, or freeform graph editor. Alignment marks and richer reference grids remain tooling-only until another real consumer proves a semantic contract.
